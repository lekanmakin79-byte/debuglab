# Debugging Portfolio

A clean Next.js portfolio for a junior web developer / application support specialist.

## Positioning

The portfolio focuses on:
- debugging and bug fixing
- React / Next.js / TypeScript
- Supabase and API troubleshooting
- deployment support
- practical project experience

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before deployment

Open `app/page.tsx` and replace:
- `YOUR_EMAIL@example.com`
- `https://github.com/YOUR_GITHUB`

You should also replace the placeholder portfolio branding if you want to use your own brand name.

## Build

```bash
npm run build
npm start
```

## Deploy

This project is suitable for Vercel or another Next.js hosting provider.
